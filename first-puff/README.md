# 第一口之前

國中菸檳教育互動遊戲，以五天的手機聊天、社群貼文和情境選擇，練習辨識誘惑、拒絕及尋求協助。

## 開啟遊戲

- 線上網址：https://angelacho1224.github.io/cho_house/first-puff/
- 電腦離線試玩：以 Chrome 開啟本資料夾的 `index.html`，填寫模擬班級、座號並按「開始」。
- 請以遊戲暱稱試玩，勿填真實姓名。

## 檔案

- `index.html`：遊戲入口。
- `game.html`：畫面、劇情、知識卡和互動程式。
- `config.js`：班級、座號上限、圖片路徑及選用的後台網址。
- `images/`：從原始資料夾整理的八張 WebP 圖片。

圖片與程式均使用相對路徑，可同時支援本機開啟及 GitHub Pages 子目錄。

## 資料記錄

目前 `API_URL` 留空，不會把班級、座號、暱稱或遊戲結果傳送到教師後台。重新整理會重新開始。字型由 Google Fonts 載入；無網路時改用電腦字型。

原始圖片、舊版壓縮檔及程式備份保留在電腦的「菸檳教育遊戲(測試)」資料夾，不納入本次發佈。

## 更新

請修改 `first-puff/` 內的正式檔案。推送到本專案 `main` 分支後，由既有 GitHub Pages 設定更新，原有冒險遊戲首頁持續可用。
