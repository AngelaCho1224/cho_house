# 三印傳說：星光之門

另有獨立的菸檳教育遊戲：[第一口之前](./first-puff/)。正式程式與圖片位於 `first-puff/`，使用方式見 [遊戲說明](./first-puff/README.md)。

結合國文與數學練習的繁體中文冒險遊戲。完成三個關卡、收集三枚憑證，再於星光之門放入對應凹槽，即可觀看五幕魔法師結局。

- 摹寫對對碰：把句子配對至五感摹寫類型。
- 五柳先生傳課文填字：拖曳或點選字卡，補完整篇課文。
- 圓周長打怪 RPG：以圓周長題目挑戰五道試煉。

開啟網站首頁即可進入；也可下載整個專案，以瀏覽器開啟 `index.html`。支援滑鼠、平板觸控與鍵盤，不需要安裝套件。

遊戲進度儲存在使用者瀏覽器的 localStorage 與 sessionStorage，不會上傳作答紀錄，也不收集學生姓名。

## 字型

使用 [辰宇落雁體 2.0](https://github.com/Chenyu-otf/chenyuluoyan_thin)，字型授權全文位於 `大冒險地圖/FONT-LICENSE.txt`。
